# Deploy checklist (Render, free/cheap path)

1. **Database** — Neon free project → copy connection string → `DATABASE_URL`
   (or Render Postgres internal URL).
2. **R2** — Cloudflare R2 bucket (public access or custom domain) + API token, set:
   `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET_NAME`, `R2_PUBLIC_BASE_URL`
3. **AI** — `GEMINI_API_KEY` (Google AI Studio). Optional: `INATURALIST_API_KEY`,
   `GOOGLE_VISION_API_KEY`, `GOOGLE_PLACES_API_KEY`. `GROK_API_KEY` not needed for MVP.
4. **SESSION_SECRET** — auto-generated by `render.yaml` (or set a long random string).
5. Render → New → Blueprint → this repo → fill the `sync: false` secrets → Deploy.
6. Verify: `curl https://<service>.onrender.com/health`
   → `{"status":"healthy","database":true}`
7. **Gate:** sign up on a phone, do one real capture, confirm the card shows in WildDex.
8. Then run the 20-Australian-species test.
